# Agent Companion v0.2.0

- 正式更名为 Agent Companion；程序命令为 `agent-companion`，Windows 附带 `agent-companion-hook` 和 `agent-companion-codex`。
- 新增 macOS Apple Silicon 独立 Codex CLI 状态栏编辑器；打开即编辑，关闭即退出，保存后无需常驻。两平台都可运行 `agent-companion codex-tui`。
- 保留预览、Apply 保存、全部隐藏、恢复 Codex 默认、原组件顺序及未知组件。写入前备份，保留注释、其他配置与文件权限；无效配置、只读文件和外部修改显示错误。
- Windows 原有任务栏、审批、通知和启动器继续提供。新目录从旧 Atoll 数据复制迁移；新环境变量兼容旧名称。hooks 升级去重并沿用卸载恢复记录，保留旧管道供旧 hooks 通信。
- Windows x86_64 ZIP 与 macOS arm64 `Agent Companion.app` ZIP 附 SHA-256 校验和及 GitHub 构建来源证明。

macOS 首版无 Developer ID 签名或 Apple 公证。首次打开方式、配置路径与平台范围见 [README](../../README.md)。
