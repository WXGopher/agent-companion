# Agent Companion v0.3.5

## macOS 按主屏自适应尺寸

- 修复拔掉外接主屏后，MacBook 上的刘海明显过宽的问题。每次切屏重新读取显示器尺寸和摄像头区域；MacBook 上窗口宽度限制在实体摄像头间隔内，数字移到刘海下缘，不再占用两侧菜单栏。
- 内容与间距随可用宽度缩放，展开后保持同宽。以 1470 点宽、摄像头间隔 179 点的屏幕为例，窗口从约 291 点收窄到 178 点；外接大屏保留 216 × 28 点，小型普通屏可收窄至 180 点。
- 大计数使用 `99+`，设置与打开 Codex 分行显示，避免窄面板里的文字换行挤压。菜单图标旁的悬停不再触发展开；可见窄条仍保留容错范围与连续展开动画。
- 原生检查覆盖显示器切换前后的实际窗口尺寸、摄像头安全区域、不同缩放分辨率、偏移原点、展开／收起和大计数，并保留逐帧动画与顶部文字检查。

v0.3.4 发布候选在正式构建中发现测试时序问题，未公开发布安装包；本版修正该检查，并保留原标签历史。

## 安装与验证

- **macOS 14+ Apple Silicon：** 下载 `agent-companion-v0.3.5-macos-arm64.zip`。退出旧刘海和设置窗口，替换“应用程序”中的 **Agent Companion.app** 后重新打开。
- **Windows x86_64：** 下载 `agent-companion-v0.3.5-windows-x86_64.zip`；首次使用需要 [Microsoft Visual C++ v14 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)。Windows 功能与 TUI 保存行为保留。
- 两个平台由 CI 和发布流程执行构建、Clippy 和自动测试。本地原生渲染与几何检查不等同于物理拔插显示器的现场检查；验证边界见 [macOS 记录](https://github.com/WXGopher/agent-companion/blob/main/docs/MACOS_NOTCH.md)。Windows 本轮以编译及自动测试验证。
- 两个 ZIP 附 SHA-256 校验和与 GitHub Actions 构建来源证明。macOS app 使用 ad-hoc 完整性签名，未做 Developer ID 签名及 Apple 公证，首次打开方式见 [README](https://github.com/WXGopher/agent-companion#macos-安装)。

## English

This release replaces the unpublished v0.3.4 candidate after correcting a timing assertion in the native display tests. Existing tags are retained.

The notch now recalculates its dimensions whenever the primary display changes. On MacBooks, it fits inside the physical camera gap with counters just below the camera, leaving both menu-bar areas clear. Content scales to the available width and expansion stays the same width. A 1470-point display with a 179-point camera gap now uses a 178-point surface instead of approximately 291 points. Large external screens retain the 216 × 28 strip; smaller ordinary screens narrow to 180 points.

Large counts use `99+`, footer actions have separate rows, and hovering menu icons beside the camera does not open the list. Native layout, display-transition, hover and continuous-animation checks cover the change. Physical cable disconnection and live hover are separate manual checks. Windows builds and automated tests continue to run in CI.

Requires macOS 14+ on Apple Silicon or Windows x86_64 with the Visual C++ v14 x64 runtime. Quit the old app and Settings before replacing it. Archives include checksums and build provenance; the macOS app is ad-hoc signed without Developer ID signing or notarization.
