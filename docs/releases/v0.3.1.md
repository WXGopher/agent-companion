# Agent Companion v0.3.1

## macOS：贴边刘海与新版设置

- 刘海跟随系统**主显示器**，在连接、断开显示器或改变主屏时重新定位。普通主屏的 216 × 28 点窄条覆盖菜单栏并贴住屏幕顶边，展开只向下延伸，保持同宽。
- 修复鼠标停在屏幕最顶边时不展开的问题。悬停判定左右各扩大 12 点、下方扩大 8 点，显示和点击区域不变；补查未送达的鼠标事件，连续移动不会反复重置展开计时。点击可固定，Esc 收起后需移出再进入才重新展开。
- 窄条、额度卡片和进度条统一显示**周剩余额度**，例如原始已用 90% 显示 `10% left`。缺失或过期读数显示 `—`；剩余不超过 10% 时进度条为橙色。
- 默认隐藏 Dock 图标。在 **Settings → Show in Dock** 中可即时开启并记住选择；从刘海打开的设置窗口共用一个可选 Dock 图标。
- 重做 macOS 设置界面：卡片分组、Cupertino 控件、跟随系统的浅色／深色外观、并排组件选择与固定实时预览，以及固定的保存和错误提示区域。
- TUI 组件仍在 **Apply changes** 后保存；保留配置备份、注释、未知组件、既有顺序及外部修改冲突保护。Dock 开关单独即时保存，不改写 Codex 配置。
- app 增加自绘图标；设置通过 Launch Services 打开并复用已有窗口。Windows 保留现有功能和编辑器布局。

## 安装与升级

- **macOS 14+ Apple Silicon：** 下载 `agent-companion-v0.3.1-macos-arm64.zip`，先退出旧刘海和设置窗口，再将解压后的 **Agent Companion.app** 替换到“应用程序”。已有 Codex 配置保留。
- **Windows x86_64：** 下载 `agent-companion-v0.3.1-windows-x86_64.zip`。退出旧程序后，运行新包的 `agent-companion.exe setup install codex` 更新程序及受管理 hooks。首次使用需要安装或更新 [Microsoft Visual C++ v14 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)。
- 两个 ZIP 附 SHA-256 校验和与 GitHub Actions 构建来源证明。macOS app 使用 ad-hoc 完整性签名，**没有 Developer ID 签名或 Apple 公证**；首次拦截时按 [Apple 官方步骤](https://support.apple.com/en-us/102445) 选择“仍要打开”。

## English

v0.3.1 improves the macOS notch and Settings. The notch follows the configured primary display and sits at the very top of the menu bar. It expands downward at the same width. Hover now includes the top screen edge plus small side/bottom margins, with pointer sampling to recover missing events and stable Escape/click behavior.

Weekly quota is shown as **percent left** throughout. The Dock icon is hidden by default and can be enabled in Settings. The redesigned settings window follows light/dark appearance and groups app preferences, component choices, a live preview and save feedback. TUI changes still require Apply; the Dock preference saves independently. The app includes a new original icon. Windows keeps its existing features and layout.

Requires macOS 14+ on Apple Silicon, or Windows x86_64 with the Visual C++ v14 x64 runtime. Quit the old app and Settings before replacing it. Both archives include checksums and build provenance. The macOS bundle is ad-hoc signed, without Developer ID signing or notarization. Automated checks are distinct from the outstanding manual scenarios listed above and in the [verification record](https://github.com/WXGopher/agent-companion/blob/main/docs/MACOS_NOTCH.md).
