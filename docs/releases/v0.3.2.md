# Agent Companion v0.3.2

## macOS 设置标题栏修复

- 修复设置窗口顶部标题栏透明、透出后方内容的问题。创建窗口时关闭原生透明模式，恢复系统不透明标题栏，并继续跟随系统外观。
- 补上原生 AppKit 窗口检查：窗口必须不透明、背景 alpha 必须为 1、透明标题栏必须关闭；在浅色／深色和窗口缩放时同样检查。原有设置内容截图无法覆盖这个区域。
- 本版不调整 TUI 保存逻辑或 Windows 功能。

## 安装与验证

- **macOS 14+ Apple Silicon：** 下载 `agent-companion-v0.3.2-macos-arm64.zip`。退出旧刘海及设置窗口，替换“应用程序”中的 **Agent Companion.app** 后重新打开。已有配置保留。
- **Windows x86_64：** 下载 `agent-companion-v0.3.2-windows-x86_64.zip`。首次使用仍需要 [Microsoft Visual C++ v14 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)。
- Windows MSVC 与 macOS arm64 由 CI 和发布流程执行构建、Clippy 和自动测试。macOS 的原生窗口属性检查已在本地通过；修复版标题栏的桌面截图未完成，不将属性检查等同于截图验收。其他手工验证边界见 [macOS 记录](https://github.com/WXGopher/agent-companion/blob/main/docs/MACOS_NOTCH.md)。
- 两个安装包附 SHA-256 校验和及 GitHub Actions 来源证明。macOS app 使用 ad-hoc 完整性签名，未做 Developer ID 签名或 Apple 公证；首次打开方式见 [README](https://github.com/WXGopher/agent-companion#macos-安装)。

## English

Fixes the transparent native title bar in macOS Settings by creating an opaque native window. The native title bar follows the system appearance. New checks inspect the actual AppKit window's opacity, background alpha and title-bar transparency in light/dark and resized settings windows; content-only snapshots did not cover this area.

Quit the old notch and Settings before replacing the app. TUI save behavior and Windows features are unchanged. Requires macOS 14+ on Apple Silicon, or Windows x86_64 with the Visual C++ v14 x64 runtime. Both archives include checksums and build provenance. The macOS bundle is ad-hoc signed, without Developer ID signing or notarization. Native window-property checks passed locally; a desktop screenshot of the fixed title bar was not obtained.
