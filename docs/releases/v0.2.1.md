# Agent Companion v0.2.1

- 修复 macOS 应用包的资源签名不完整问题：打包后为整个 `.app` 生成 ad-hoc 完整性签名，并执行严格验证。
- 继续提供 Apple Silicon 独立 Codex CLI 状态栏编辑器；关闭即退出，保存的设置无需后台进程。
- Windows 保持 v0.2.0 的功能，三个程序与平台校验和一同提供。
- 发布包由 GitHub Actions 构建，附 SHA-256 校验和及构建来源证明。

ad-hoc 签名不使用 Developer ID，也不代表 Apple 公证。首次打开仍按 [Apple 官方步骤](https://support.apple.com/en-us/102445) 选择“仍要打开”。

新增的 macOS Codex 刘海在 v0.3.0 开发分支中，本修复版仍为独立编辑器。
