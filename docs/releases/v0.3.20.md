## English

- **Clearer macOS menu-bar status dots.** Increase two-row dots from 5 pt to 7 pt and single-row dots from 6 pt to 8 pt. Use stronger blue, green and yellow fills, brighter gray, and clearer dark/light outlines against wallpaper.
- **Stay visible while breathing.** Keep the two-second running animation, raising its opacity range from 45%–100% to 80%–100%. Continue respecting Reduce Motion and stopping animation when hidden or no longer running.
- **Preserve status meanings and interactions.** Task priority, percentage text, tooltips, VoiceOver labels, clicks and Command-drag placement retain their behavior. Popup and Windows palettes, account data, configuration, quota refresh and dual-instance launch logic are unchanged.

Validation: targeted native menu-bar checks passed, using synthetic tasks and quota values on light, dark and blue backgrounds, including the dim animation phase. The local App passed signature and launch checks. Full installed-popup interaction and manual Windows desktop regression are not claimed as completed. Release builds continue to run compilation, Clippy and automated tests on both platforms.

The public preview uses synthetic data and excludes EXIF and text metadata. GitHub Actions builds release assets; downloaded checksums, architectures, macOS signatures and provenance are verified before publication. Local configuration, credentials, logs, backups and locally compiled binaries are excluded. The macOS package requires macOS 14+ on Apple Silicon and uses an ad-hoc integrity signature without Apple notarization.
