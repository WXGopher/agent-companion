# Agent Companion v0.3.19

- **修复旧版 Dodex 桌面启动**：新增 `agent-companion dodex-app` 校验和 `--repair` 显式修复。已审计旧启动器绑定独立配置与桌面目录，TUI 不再被误判为已运行的桌面 App。Companion 创建的环境也支持校验，无需旧版修复。
- **恢复中断的启动器发布**：校验迁移清单、目标与备份后继续发布或清理完成标记；冲突文件保留。修复不迁移账号、配置或会话，也不终止运行中的 TUI。
- **兼容 Finder 自定义图标**：保留官方身份与资源完整性验证；仅在私有文件系统克隆中去掉已识别的图标元数据，再进行严格签名校验，已安装程序不被改写。
- **可选的旧环境整理工具**：源码仓库提供入口合并、主／副 CLI 环境隔离、延后归档旧运行包和 Dock 固定／最近项目清理。保留工作目录、参数、代理和沙箱上下文。新快照与旧布局区分，避免回滚恢复过时路径。

修复与整理仅支持已审计的旧环境；未知版本保留并拒绝覆盖。整理脚本需要源码 checkout，不随 App 安装，也不会在升级时自动执行。写入发布日志前强制终止可能需要人工检查残留目录；自定义图标校验需要支持 macOS 克隆的文件系统。Dock 最近项目仍可能由系统再次加入。

本版没有 Windows 功能改动；两平台仍执行构建、Clippy 和自动测试。回归测试使用合成配置和临时目录，覆盖隔离、签名、进程区分、并发冲突与中断恢复。未将人工 Windows 桌面检查、完整交互式 TUI 回归或无法自动化的 macOS App 界面检查标为完成。

公开源码与安装包不包含个人图标草稿、生成图像元数据、本机记录、配置、凭据或备份。安装包由 GitHub Actions 构建，下载验证校验和、架构、签名与来源证明后公开。macOS 需要 macOS 14+ 和 Apple Silicon，使用 ad-hoc 完整性签名，未做 Apple 公证。

## English

- **Repair legacy Dodex desktop startup.** Add `agent-companion dodex-app` validation and explicit `--repair`. Audited legacy launchers bind independent profile and desktop directories without treating a running TUI as a desktop App. Companion-managed environments also validate and need no legacy repair.
- **Recover interrupted launcher publication.** Validate manifests, destinations and backups before continuing or clearing completion records. Preserve conflicting files. Repair does not migrate accounts, configuration or sessions, or terminate running TUIs.
- **Support Finder custom icons.** Retain official identity and sealed-resource verification. Remove only recognized icon metadata from a private filesystem clone before strict signature verification; leave the installed program unchanged.
- **Optional legacy cleanup tools.** The source checkout includes entry consolidation, primary / secondary CLI environment isolation, deferred old-runtime archival and cleanup of known pinned / recent Dock items. Preserve cwd, arguments, proxies and containment context. Separate new snapshots from obsolete layouts to prevent restoring outdated paths.

Repair and consolidation accept only audited legacy versions; unknown files remain untouched. Maintenance scripts require a source checkout and are not installed or automatically executed with the App. A forced exit before the publication journal exists may require inspecting the incomplete directory. Custom-icon validation requires macOS filesystem cloning. macOS may add recent Dock entries again later.

There are no Windows feature changes; builds, Clippy and automated tests still cover both platforms. Regression tests use synthetic configuration and temporary directories for isolation, signatures, process detection, conflicts and interruption recovery. Manual Windows desktop checks, full interactive TUI regression and unavailable macOS App UI automation are not claimed as completed.

Public source and packages exclude personal icon experiments, image-generation metadata, machine records, configuration, credentials and backups. GitHub Actions builds the packages; checksums, architecture, signatures and provenance are verified after download and before publication. macOS requires macOS 14+ and Apple Silicon; its bundle has an ad-hoc integrity signature without Apple notarization.
