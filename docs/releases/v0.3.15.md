# Agent Companion v0.3.15

- Windows 新增可选 Dodex 双开：在设置中部署、校验并打开独立的第二实例，分别管理登录、历史、任务、用量和 CLI 状态栏配置。
- Windows 任务栏分别显示 Codex（`C`）与 Dodex（`D`）的每周剩余额度；详情面板提供实例选择和周额度卡片。
- 托盘和任务栏右键菜单均可一键打开 Dodex；Tasks 页只保留实例额度卡片，移除重复的 Codex 额度条。
- Windows Usage 按实例缓存五分钟，从查询完成时计时。手动刷新立即重新查询；过期或已跨过重置时间的账号额度不会覆盖有效的新读数。
- 修复 Windows 首次初始化中辅助程序目录归属导致的 `helper_failed`；提前创建当前用户所有的目录，保留已有辅助程序。
- 更新中英文安装、双开启动及隔离说明，并增加使用合成数据的 Windows 双开设置截图。

Windows 双开需要已安装且签名有效的官方 Microsoft Store Codex / ChatGPT 应用，默认关闭。新实例不复制原账号凭证或个人配置；首次使用需自行登录并完成 Windows 初始化。运行程序的自动更新和卸载暂不支持。

验证：Windows 部署、双账号用量读取、沙箱就绪状态和本地命令执行已通过；自动测试覆盖部署边界、缓存隔离、配置草稿及 100% / 150% / 200% 界面缩放。Dodex 真实桌面会话跳转尚未完成实机验收。macOS 仍需 macOS 14+ 和 Apple Silicon，安装包使用 ad-hoc 完整性签名，未做 Apple 公证。

## English

- Optional Dodex support on Windows: deploy, validate and open an isolated second instance from Settings, with separate login, history, tasks, usage and CLI status bar configuration.
- The Windows taskbar shows separate weekly quota readings for Codex (`C`) and Dodex (`D`). The details panel adds instance selection and weekly quota cards.
- Both tray and taskbar context menus open Dodex directly. The Tasks page keeps the instance quota cards and removes duplicate Codex quota bars.
- Windows Usage caches each instance for five minutes from completion. Manual refresh reads immediately; stale or reset account readings do not mask valid new quota data.
- Fix Windows first-run `helper_failed` caused by sandbox helper directory ownership. Prepare the directory as the current user before elevated setup, preserving existing helpers.
- Update bilingual installation, launch and isolation guidance, with a synthetic Windows second-instance settings screenshot.

Windows second-instance support requires the installed, validly signed official Microsoft Store Codex / ChatGPT app and is disabled by default. It copies no original account credentials or personal settings. Sign in and complete Windows setup on first use. Automatic runtime updates and uninstall are not included.

Validation: Windows deployment, separate account usage reads, sandbox readiness and local command execution passed. Automated coverage includes deployment boundaries, cache isolation, configuration drafts and 100% / 150% / 200% UI scaling. Real Dodex desktop thread navigation has not yet been manually verified. macOS still requires macOS 14+ and Apple Silicon; its bundle uses an ad-hoc integrity signature without Apple notarization.
