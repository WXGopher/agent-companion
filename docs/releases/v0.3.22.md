# Agent Companion v0.3.22

- **额度刷新**：macOS 与 Windows 使用统一查询服务。启动、定时到期和主动打开面板时查询所有已启用实例，手动刷新仅查询当前实例。默认间隔为 5 分钟，可在设置中调整为 1–60 分钟整数；保存到独立的 `usage.json`，运行中生效并重新计时。每次刷新只进行必要握手和一次 `account/rateLimits/read` 业务调用，20 秒超时；不预查登录、不附带历史查询、不创建模型任务、不消耗推理 Token。这不保证 CLI 内部只有一次 HTTP 请求。历史 Token 统计在进入 Usage 或切换该页实例时独立加载，并缓存 5 分钟。
- **读数与失败提示**：始终展示最后成功查询值；仅查询失败后在旧值旁加 `*`，再次成功后清除。无读数时显示 `—`。经过时间或跨过重置时间不会加星号，也不会将额度推算为 100%；悬停及 Usage 可查看最后成功时间和失败原因。本地会话日志不再更新 GUI 额度，账号查询结果不落盘。
- **呼吸状态**：运行状态在亮蓝色 `#32B8FF` 与灰色 `#92979F` 之间平滑变化，保持不透明，完整周期为 2 秒；其他呼吸颜色使用相同节奏。蓝色运行、黄色等待或失败、绿色全部完成、灰色空闲或停止的含义不变。
- **设置界面**：统一按钮、路径字段和字体，调整亮暗主题的中性色；macOS 设置使用苹方字体，让通用设置、CLI 状态栏和双开配置保持一致。
- **更新提示**：主动打开面板时在后台查询 GitHub 正式版本，每 24 小时最多检查一次，成功和失败尝试都计入间隔，记录保存到独立的 `updates.json`。检查有 4 秒超时，不阻塞面板；失败时保留已有提示。只有更高的正式版本才显示更新入口，点击打开对应 Release 页面，不自动下载或安装。悬停预览不触发检查。

切页、切实例、任务活动、绘制和额度重置不会触发额度查询。相同实例的同类请求合并；成功或失败后均等待设定间隔，不额外重试。关闭面板不取消额度请求，额度刷新不刷新历史统计。

macOS 包适用于 macOS 14+ Apple Silicon，使用 ad-hoc 完整性签名，未做 Apple 公证。

## English

- **Quota refresh.** macOS and Windows share one query service. Startup, a due timer and intentionally opening the panel query every enabled instance; manual refresh queries only the selected instance. The default interval is five minutes, configurable to an integer from 1–60 minutes. It is stored separately in `usage.json`; saving applies immediately and restarts the interval. Each refresh performs the required handshake and one `account/rateLimits/read` business call with a 20-second timeout. It does not precheck login, bundle history, create a model task or consume inference tokens; this does not guarantee a single HTTP request inside the CLI. Token history loads independently when entering Usage or switching its instance and is cached for five minutes.
- **Readings and failures.** Keep the last successful reading. A failed query adds `*` to the retained value until the next success; unavailable readings show `—`. Elapsed time and quota resets neither add a star nor imply 100% remaining. Hover text and Usage show the last success time and failure reason. Local session logs no longer update GUI quota, and account query results are not saved to disk.
- **Breathing status.** Running indicators smoothly alternate between bright blue `#32B8FF` and gray `#92979F`, remaining opaque through a complete two-second cycle. Other breathing colors use the same timing. Blue still means running, yellow waiting or failure, green all tasks completed, and gray idle or stopped.
- **Settings.** Align buttons, path fields and typography, with neutral colors for light and dark themes and PingFang on macOS. General settings, the CLI status bar editor and dual-instance configuration share the same presentation.
- **Update hints.** Intentionally opening the panel checks GitHub for a stable release in the background, at most once every 24 hours. Successful and failed attempts both count toward the interval, persisted separately in `updates.json`. A four-second timeout keeps failures bounded without delaying the panel; failures retain any known update. Only a newer stable version shows an update button, which opens that version's Release page without downloading or installing it. Hover previews do not check for updates.

Page and instance switches, task activity, rendering and quota resets do not trigger quota queries. Overlapping requests of the same type and instance merge. Success and failure both restart the configured interval without extra retries. Closing the panel does not cancel quota requests, and quota refresh does not reload token history.

The macOS package requires macOS 14+ on Apple Silicon and uses an ad-hoc integrity signature without Apple notarization.
