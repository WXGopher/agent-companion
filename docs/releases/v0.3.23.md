# Agent Companion v0.3.23

- **macOS Dodex App**：从本机签名有效的官方 Codex App 创建独立镜像，使用固定的公开 App 路径、自有名称、图标与本地签名。原生入口在同一进程内启动应用，让 Finder、Dock 与 Companion 跳转使用同一个 App；不修改官方 App。
- **启动同步**：轻量比较官方 App 的版本与构建号，一致时直接启动，不复制或重新签名。有更新时先构建并验证副本，再原子替换；来源或更新程序不可用、同步失败时仍打开现有 App。运行中的 Dodex 不会被替换。已有镜像需手动“检查并同步”一次以启用启动检查；实际升级可能再次触发 macOS 钥匙串授权。
- **保留 TUI 与账号环境**：已有 TUI 命令、运行程序及更新方式保持不变，继续使用原有第二账号目录、登录、个人配置和会话。App 同步不覆盖这些文件，Companion 接入开关只控制任务与用量监控。新环境不复制原实例账号数据，首次使用需自行登录。
- **双开设置**：分别展示 Dodex App、Companion 接入和副账号与 TUI，避免把已有 TUI 当作 App 已安装。打开页面只读取安装信息与保存的路径；该页的 App 校验与同步仅由“安装 Dodex App”或“检查并同步”触发。配置与个人指令仍使用独立的手动同步操作。

本次 App 同步行为仅适用于 macOS Dodex App；Windows 运行程序保持原有行为。macOS 包适用于 macOS 14+ Apple Silicon，使用 ad-hoc 完整性签名，未做 Apple 公证。详见 [Dodex App 说明](https://github.com/WXGopher/agent-companion/blob/v0.3.23/docs/macos-dual-instance.md)。

## English

- **macOS Dodex App.** Create a local mirror of the validly signed official Codex App with a stable public path, its own name and icon, and a local signature. A native entry starts the application in the same process, so Finder, Dock and Companion navigation use one App. The official App is untouched.
- **Startup synchronization.** Compare the official App's version and build with a lightweight check. Matching builds launch without copying or signing again. Changed builds are staged and verified before atomic replacement; an unavailable source or updater, or a failed synchronization, leaves the existing App available to open. Running Dodex processes are never replaced. Existing mirrors need one manual sync to enable startup checks. Actual upgrades may prompt for macOS Keychain access again.
- **Existing TUI and account environment.** Preserve TUI commands, executables and update behavior, along with the existing second-account directories, login, personal settings and sessions. App synchronization does not overwrite these files, and the Companion switch controls task and usage monitoring only. Fresh environments do not copy the primary account's data and require their own login.
- **Dual-instance Settings.** Separate Dodex App, Companion monitoring, and the second account and TUI, so an existing TUI no longer implies that the App is installed. Opening the page reads installation metadata and saved paths. App verification and synchronization on that page start only through the install or sync button. Configuration and personal instructions retain their separate manual sync actions.

This App synchronization behavior applies only to macOS Dodex App; Windows runtimes retain their existing behavior. The macOS package requires macOS 14+ on Apple Silicon and uses an ad-hoc integrity signature without Apple notarization. See the [Dodex App guide](https://github.com/WXGopher/agent-companion/blob/v0.3.23/docs/macos-dual-instance.md).
