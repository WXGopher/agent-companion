# Agent Companion v0.3.9

## 更窄的菜单栏摘要

- 左侧只显示 **Codex 周剩余额度百分比**，省略 `left`。右侧显示绿色工作图标和正在工作的会话数；有待审批或待输入的会话时，额外显示一个橙色 `?`。
- 等待中的会话不再计入工作数；多个等待会话共用一个问号。完成数保留在展开的 Finished 列表。没有工作时显示灰色 `0`；剩余额度不超过 10% 时显示橙色，缺失或过期时显示 `—`。
- 内置屏摄像头两侧按各自内容独立收窄，为相邻菜单图标留出更多空间。180 点摄像头样例中，`68%` 加一位工作数为 **243 × 32 点**，有问号时为 **253 × 32 点**。摄像头留白、菜单栏对齐、同宽向下展开及连续收起动画保持不变。
- 保留 Settings 中的跟随主屏／指定显示器选项。README 中英文说明及刘海截图同步更新。

## 安装与验证

- **macOS 14+ Apple Silicon：** 下载 `agent-companion-v0.3.9-macos-arm64.zip`。退出旧刘海及设置窗口，替换“应用程序”中的 **Agent Companion.app** 后重新打开。
- **Windows x86_64：** 下载 `agent-companion-v0.3.9-windows-x86_64.zip`；首次使用需要 [Microsoft Visual C++ v14 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)。
- 原生检查覆盖 21 种布局，包括工作／等待混合、仅等待、多个等待会话、空闲、低／满额度及 `99+`；像素检查验证颜色、摄像头留白、文字单行和条件问号。继续检查连续动画、双屏几何、显示器偏好、长内容和设置窗口。
- 用户已在双屏环境手动选择内置屏并确认位置正常。物理拔插、全屏和 Terminal.app 跳转仍未手工覆盖。Windows 按编译和自动测试验收，详见[验证范围](https://github.com/WXGopher/agent-companion/blob/main/docs/MACOS_NOTCH.md)。
- 两个平台均通过 GitHub Actions 构建、Clippy 和自动测试。安装包附 SHA-256 校验和与构建来源证明；macOS 为 ad-hoc 完整性签名，未做 Developer ID 签名或 Apple 公证，首次打开方式见 [README](https://github.com/WXGopher/agent-companion#macos-安装)。

## English

The compact strip now shows only **weekly quota remaining** on the left, without `left`. The right side shows a green icon and the number of **sessions currently working**, plus one orange `?` when any session needs approval or input. Waiting sessions are excluded from the working count; completed tasks remain in the expanded Finished list. Idle counts are gray, low quota is orange, and missing or expired quota shows `—`.

Each camera-side area is measured independently to reclaim menu-bar space. With a 180-point camera reservation, `68%` and a single-digit working count occupy 243 × 32 points, or 253 × 32 with a question mark. Camera clearance, menu-bar alignment, constant-width expansion and continuous animation are preserved. Display selection remains available in Settings. The bilingual README and notch screenshot are updated.

Native checks cover 21 layouts, state transitions, conditional question marks, color pixels, camera clearance, display geometry, preferences, animation and settings. The user confirmed correct placement after selecting the built-in display in a dual-display setup. Physical hot-plugging, fullscreen and Terminal.app navigation remain outside manual acceptance. Windows validation covers compilation and automated tests.

Requires macOS 14+ on Apple Silicon or Windows x86_64 with the Visual C++ v14 x64 runtime. Quit the old app and Settings before replacing it. Archives include checksums and build provenance; the macOS app is ad-hoc signed without Developer ID signing or notarization.
