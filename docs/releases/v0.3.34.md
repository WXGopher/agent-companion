# v0.3.34

修复 Codex 已通过 ChatGPT 登录、Companion 却无法显示订阅额度和 Token 历史的问题。
当 `config.toml` 保留 `windows_wsl_setup_acknowledged`、`auto_apply_patches` 等
当前 Codex 会忽略的旧字段时，先前的用量查询进程因强制启用 `--strict-config`
而在握手前退出，只显示笼统的查询失败提示。

用量查询现在沿用 Codex 默认的配置兼容行为，不改写个人配置，也不需要重新登录。
认证归属、有效认证存储、服务地址、数据库目录和托管要求的校验继续执行。
回归覆盖 Codex 与 Dodex 的额度和历史查询，并验证配置文件保持原样。

本次发布也包含主分支已合入的 Claude Code 支持移除；Agent Companion 专注于
Codex 和 Dodex 的任务、订阅用量与 TUI 双开。

Fix subscription quota and token-history reads failing even though Codex is
signed in with ChatGPT. The usage worker previously forced `--strict-config`,
so ignored legacy settings such as `windows_wsl_setup_acknowledged` and
`auto_apply_patches` caused it to exit before the protocol handshake.

Usage reads now follow normal Codex configuration loading without changing
personal settings or requiring another login. Account ownership, effective
authentication storage, service, database and managed-policy checks remain in
place. Regression coverage exercises both Codex and Dodex quota/history reads
and verifies that user configuration is preserved.

This release also includes the removal of Claude Code support already merged
into main. Agent Companion now focuses on Codex and Dodex tasks, subscription
usage and independent TUIs.

See [usage query behavior](../USAGE_QUERIES.md) and the
[Windows verification record](../WINDOWS_VALIDATION.md).
