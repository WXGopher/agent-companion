# Agent Companion v0.3.27

- **托管配置与额度查询**：修复仅因系统 `requirements.toml` 存在就拒绝读取订阅用量的问题。已知的非认证 hooks、审批、沙箱、权限和网络要求继续交给原生 Codex 执行，不再被身份预检误拦。认证限制、未知要求、无法解析的配置、旧式托管配置与 macOS MDM 设置仍明确报错；发送额度请求前继续核验原生有效配置。
- **复用已有 Codex**：macOS 用量查询可发现已有原生 TUI，不再要求更新功能使用的完整安装包清单；支持从官方 npm 的嵌套、提升和内置布局解析原生程序，并保留 Codex App 回退。无需另设 API Key，不执行未知 wrapper 或 npm JavaScript 入口，也不借用已知 Dodex 运行程序。
- **账号隔离**：保留账号、工作区、认证存储和服务来源核验。换号、登出或无法确认身份时清除旧读数；慢历史查询不阻塞额度。

自动验收：**29 项用量测试通过**，覆盖托管配置、两代 npm 原生程序路径的六种布局组合、App 回退、副实例排除、账号切换、结果发布及超时。工作区全目标严格 Clippy（`-D warnings`）、格式和差异检查通过。

macOS 已安装的本地修复构建恢复了剩余额度、累计 Token 和最近七个有记录日期的用量。使用既有 ChatGPT 登录，原生 CLI **0.160.1** 与 App 内置原生程序 **0.155.0** 均通过有效配置和额度探测；未创建模型任务。npm 布局由合成文件夹具验证。**Windows GUI 尚未实机验证。** 详见[查询行为与验证记录](https://github.com/WXGopher/agent-companion/blob/v0.3.27/docs/USAGE_QUERIES.md)。

macOS 包适用于 macOS 14+ Apple Silicon，使用 ad-hoc 完整性签名，未做 Apple 公证。

## English

- **Managed settings and usage queries.** Fix subscription usage being rejected merely because system `requirements.toml` exists. Known non-authentication hook, approval, sandbox, permission and network requirements remain enforced by native Codex without being rejected by the identity precheck. Authentication restrictions, unknown requirements, malformed files, legacy managed settings and macOS MDM settings still show an explicit error. Native effective configuration is verified before sending a quota request.
- **Reuse existing Codex installations.** macOS usage discovery accepts installed native TUI binaries without requiring the complete package manifest used by the updater. Resolve native binaries from official npm's nested, hoisted and bundled layouts, with Codex App fallback. No separate API key is needed. Unknown wrappers, npm JavaScript entry points and known Dodex runtimes are not executed for primary-instance discovery.
- **Account isolation.** Retain checks for account, workspace, authentication storage and service source. Account changes, logout or unverifiable ownership clear previous readings. Slow history queries do not delay quota.

Automated validation: **29 usage tests passed**, covering managed settings, six npm layout combinations across two native-path generations, App fallback, secondary-instance exclusion, account changes, result publication and timeouts. Strict workspace all-target Clippy (`-D warnings`), formatting and diff checks passed.

An installed local macOS fix build restored remaining quota, lifetime tokens and the last seven reported days of usage. Using the existing ChatGPT login, native CLI **0.160.1** and bundled App runtime **0.155.0** both passed effective-configuration and quota probes; no model task was created. npm layouts were verified with synthetic filesystem fixtures. **Windows GUI remains unverified.** See [query behavior and validation](https://github.com/WXGopher/agent-companion/blob/v0.3.27/docs/USAGE_QUERIES.md).

The macOS package requires macOS 14+ on Apple Silicon and uses an ad-hoc integrity signature without Apple notarization.
