# Agent Companion v0.3.0

## macOS：Codex 窄刘海与 TUI 设置

- 左侧显示活动任务数、最近十五分钟结束的任务数；右侧显示 Codex 原生周额度**已用百分比**。没有有效读数时显示 `—`。
- 尽量缩窄摄像头两侧内容；展开面板与收起时同宽，只向下展开。普通显示器使用 216 点宽的窄条。
- 悬停预览、点击固定、Active / Finished 切换、列表滚动、Esc 或外部点击收起。
- 点击任务返回 Codex 桌面对话，或按存活进程的 tty 定位 Terminal / iTerm2 会话，兼容 iTerm2 独立会话服务。无法定位时显示错误与复制恢复命令。
- 展开后的齿轮 **Settings** 打开 Codex CLI 状态栏定制，支持预览、Apply、全部隐藏和恢复默认；再次点击聚焦已打开的设置。
- `agent-companion codex-tui` 保留独立编辑器。保存的配置由 Codex 读取，关闭编辑器后重启 Codex CLI 生效。
- 修复过期悬停事件导致 Esc 后立即展开、大计数和窄屏按钮显示、过期跳转回调干扰新面板，以及读取持续失败后旧任务保持运行状态的问题。

## 安装与升级

- **macOS 14+ Apple Silicon：** 下载 `agent-companion-v0.3.0-macos-arm64.zip`，退出旧刘海及设置窗口，将解压后的 app 替换到“应用程序”。v0.2.x 的默认编辑器入口移到刘海 Settings，已有配置保留。
- **Windows x86_64：** 下载 `agent-companion-v0.3.0-windows-x86_64.zip`。保留现有任务栏、审批、通知与启动器功能。升级前退出旧程序，再运行新包的 `agent-companion.exe setup install codex` 更新程序与受管理 hooks。
- Windows 首次使用需要安装或更新 [Microsoft Visual C++ v14 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)，用于提供程序依赖的 `VCRUNTIME140.dll`；ZIP 不包含运行库安装器。详见 [Microsoft 官方说明](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。
- 两个平台均附 SHA-256 校验和与 GitHub Actions 构建来源证明。macOS app 经过完整的 ad-hoc 资源签名检查，**没有 Developer ID 签名或 Apple 公证**。首次拦截时按 [Apple 官方步骤](https://support.apple.com/en-us/102445) 选择“仍要打开”。

## 验证与边界

- Windows MSVC、macOS arm64 构建、Clippy、公共与平台自动测试纳入发布流程；macOS 还检查 11 种原生布局、同宽展开/收起和异步跳转状态。
- macOS 核心窗口流程已实机检查，Windows 按本轮范围验证编译与自动测试。物理显示器切换、全屏及 Terminal.app 跳转尚未手工覆盖；iTerm2 返回匹配成功，但自动化工具禁止直接读取其窗口，未独立核对选中标签页。
- macOS 仅支持本地 Codex；不加入其他代理、宠物或主题编辑。终端跳转可能需要 Automation 授权；tmux、SSH、IDE 等不保证精确分屏。桌面存储读取仍为实验性兼容。
- 采用 **GPL-3.0-only**，Open Island 复用代码与固定来源见包内 `THIRD_PARTY_NOTICES.md`。

## English

v0.3.0 adds a Codex-only macOS notch with active/recently finished counts, native weekly usage, and a task panel that expands downward without widening. The Settings gear opens the existing Codex CLI status bar editor. Task navigation supports Codex conversations and live Terminal/iTerm2 sessions, including detached iTerm servers, with resume-command recovery when selection fails.

Requires macOS 14+ on Apple Silicon; Windows x86_64 retains its existing features. Quit the old app and Settings before replacing it. Saved Codex configuration is preserved. Both archives include checksums, build provenance and GPL-3.0-only notices. The macOS app is ad-hoc signed for integrity, without Developer ID signing or notarization. See the [README](https://github.com/WXGopher/agent-companion#english) for installation and verification limits.

Windows requires the [Microsoft Visual C++ v14 x64 Redistributable](https://aka.ms/vc14/vc_redist.x64.exe), which is not bundled in the archive. Install or update it before first use.
