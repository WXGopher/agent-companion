# Agent Companion v0.3.14

- macOS 菜单栏直接显示每周剩余额度，采用紧凑数字样式。Codex 和 Dodex 都有有效读数时上下两行显示，Codex 在上；仅一份有效时显示单行，均无有效读数时显示默认图标。
- 菜单栏沿用各实例的本地读数和最近 5 分钟账号缓存，关闭面板后仍更新，不额外发起账号查询。已跨过重置时间的缓存不会遮住新的有效本地额度。
- 新安装默认仅显示菜单栏，Dock 和刘海关闭。三个入口仍可在设置中独立开关，已有保存的选择保持不变。

macOS 需要 macOS 14+ 和 Apple Silicon。安装包使用 ad-hoc 完整性签名，未做 Apple 公证。Windows 行为不变。

验证说明：本地完整 macOS 原生界面回归、菜单栏有效性及缓存隔离检查、设置页集成检查和签名验证已通过；测试和渲染使用合成数据。本机安装及 Dock 隐藏状态已确认。Windows 人工桌面检查未在本机进行；两个平台的发布构建与自动测试由 GitHub Actions 执行，安装包下载核验后公开。

## English

- The macOS menu bar now shows weekly quota remaining with compact figures. Valid Codex and Dodex readings appear in two stacked rows, Codex above Dodex. A single valid reading uses one row; no valid readings restore the default icon.
- The menu bar reuses each instance's local readings and recent five-minute account cache, including while the panel is closed, without starting additional account requests. A cache whose quota has reset no longer hides a valid new-period local reading.
- Fresh installations show only the menu bar by default, with the Dock and notch off. Settings still controls all three independently and preserves previously saved choices.

macOS requires macOS 14+ and Apple Silicon. The app has an ad-hoc integrity signature and is not Apple-notarized. Windows behavior is unchanged.

Validation: the full local native macOS UI suite, menu-bar validity and cache-isolation checks, Settings integration checks and signature verification passed, using synthetic test and render data. Local installation and the hidden Dock state were confirmed. Manual Windows desktop checks were not performed locally. GitHub Actions builds and tests both platforms; release assets are published after download verification.
