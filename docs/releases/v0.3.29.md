# v0.3.29

桌面双开已移除，macOS 和 Windows 只保留官方 Codex App。设置中的 **TUI 双开**
独立安装、修复、监控和更新 Codex TUI / Dodex TUI，两套版本可以不同。

`dodex update` 直接更新自身的完整官方 standalone 包，默认使用原生 daemon；
`dodex app` 明确提示不再支持。新入口 `agent-companion dodex-tui --install/--repair`
接入已有副账号目录、历史、数据库和日志，不复制主账号认证，也不强制结束终端。

The desktop mirror and paired updates are removed. The two TUIs own separate
accounts, packages, daemons and update directories. Codex retains its original
installation channel. Settings shows two independently updateable TUI rows;
Dodex task navigation opens or resumes a terminal session. Explicit config sync
and account handoff remain available.

See [TUI installation, migration and recovery](../macos-dual-instance.md).
