# Agent Companion v0.3.29

- **修复 Windows 额度查询**：原生程序返回的普通路径与 Companion 使用的 Windows 扩展路径可能指向同一数据库目录，旧版却将它们判为不同来源并拦截查询。现在按实际目录核验，恢复受影响的 Codex / Dodex 每周额度，保留账号隔离检查，无需因这一问题重新登录。
- **Windows 双开入口补齐**：部署后在开始菜单搜索 Dodex 即可打开独立桌面 App，无控制台窗口；终端中的 `dodex` 继续打开 CLI，两个入口共用独立副账号。GUI / CLI 启动器安装在固定位置，升级可修复已知旧入口并保留已有账号、会话和设置。
- **兼容已有安装方式**：保留新版部署登记与维护能力。未安装官方 standalone TUI 时，可使用已验签桌面包内置的原生 CLI，不改动现有 npm Codex 命令。版本页识别并标注 App 内置 CLI，对齐支持这一来源；独立 TUI 的官方稳定版更新仍要求受支持的完整 standalone 包。
- **独立显示双账号状态**：Windows 任务栏以 `C` / `D` 区分 Codex / Dodex 的每周剩余额度及任务状态。等待、运行、完成等状态按实例显示；尚无读数和查询失败也各自保留明确状态。

Windows 双开改动的本地自动检查 **583 项通过、10 项忽略**，静态检查与 release 构建通过；后续额度修复的 **26 项相关测试通过**。另行授权的生产查询与 Windows 显示数据快照检查确认两个已有账号均可读取每周额度，没有创建模型任务。本机已替换并重启修复构建，保留原账号；**桌面自动化不可用，最终任务栏与面板外观尚未目视验收**。以上为分阶段本地结果，最终版本的双平台 CI 与发布构建结果单独记录。详见 [Windows 验证记录](https://github.com/WXGopher/agent-companion/blob/v0.3.29/docs/WINDOWS_VALIDATION.md)。

已有 Windows 双开环境可从新版程序运行 `.\agent-companion.exe dodex --deploy`，补齐或修复开始菜单与 CLI 入口。macOS 包适用于 macOS 14+ Apple Silicon，使用 ad-hoc 完整性签名，未做 Apple 公证。

## English

- **Repair Windows quota queries.** Native Codex can report an ordinary path to the same database directory that Companion represents with an extended Windows path. The previous check treated them as different sources and rejected the query. Verify the actual directory to restore affected Codex / Dodex weekly readings while retaining account-isolation checks. This issue does not require signing in again.
- **Complete the Windows dual-instance entry points.** Search for Dodex in Start to open its independent desktop app without a console window. The terminal's `dodex` command still opens the CLI; both share the secondary profile. GUI and console launchers use stable locations, and upgrades repair known older entries while retaining accounts, sessions and settings.
- **Support existing installation layouts.** Retain current deployment registration and maintenance behavior. If the official standalone TUI is absent, use the verified desktop package's bundled native CLI without changing existing npm Codex commands. The version panel identifies the app-bundled CLI and alignment supports this source. Updating a standalone TUI from the official stable channel still requires a supported complete standalone package.
- **Show each account's status separately.** Windows taskbar labels `C` / `D` distinguish Codex / Dodex weekly quota and task status. Waiting, running and completed tasks, unavailable readings, and query failures remain separate for each instance.

Local Windows checks for the dual-instance changes reported **583 passed and 10 ignored**, with static checks and the release build passing. The subsequent quota repair passed **26 related tests**. A separately authorized production-query and Windows display-snapshot check confirmed weekly readings for both existing accounts without creating a model task. The repaired local build was installed and restarted with existing accounts retained. **Desktop automation was unavailable, so the final taskbar and panel appearance has not been visually accepted.** These are staged local results; final-version cross-platform CI and release-build results are recorded separately. See the [Windows validation record](https://github.com/WXGopher/agent-companion/blob/v0.3.29/docs/WINDOWS_VALIDATION.md).

For an existing Windows deployment, run `.\agent-companion.exe dodex --deploy` from the new release to add or repair Start menu and CLI entry points. The macOS package requires macOS 14+ on Apple Silicon and uses an ad-hoc integrity signature without Apple notarization.
