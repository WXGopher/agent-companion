# Agent Companion v0.3.25

修复 `acomp resume` 在现存 Codex / Dodex 配置下无法启动的问题：

- **停用的 MCP**：显式 `enabled=false` 的定义不再因残留相对命令、工作目录或未使用的 OAuth 配置阻止接力。启动前仍通过原生最终配置核验其保持停用；活跃 MCP 和其他兼容性检查保留。
- **项目配置边界**：按原生 Git 根规则扫描项目配置，避免把仓库上方另一账号的 `.codex` 误当项目设置。空 `.git` 目录不会遮蔽有效父仓库，worktree 文件标记继续受支持。
- **旧 Dodex 运行程序**：先验证现有部署绑定，再允许借用本机官方 App 或固定 standalone 安装中的原生程序，仍严格要求 **0.159.3**。历史、设置及所选账号来源不变，不升级或替换现有 Codex / Dodex 入口。原生程序可能迁移历史库；临时夹具已验证 **0.155.0-alpha.16.4 → 0.159.3 → 旧版** 的读取、分页、继续写入和写入锁兼容性。

自动验收：核心 **275**、主程序 **166**、`acomp` **15** 项通过，共 **456** 项；另有 **2** 项既有真实数据测试保持忽略。CLI 集成 **6/6** 通过；原生契约 **15 项分批通过**，其中 13 项使用外层沙箱，另 2 项使用测试自身沙箱以避开 macOS 嵌套沙箱限制。macOS 与 Windows GNU 相关 Clippy、格式和差异检查通过。

macOS 真实来源／账号四组合（Codex/Codex、Dodex/Dodex、Codex/Dodex、Dodex/Codex）均通过原生预检并进入 TUI 输入就绪状态，Ctrl-D 退出码均为 **0**。**未提交新模型请求，未验证订阅计费。Windows 恢复启动仍禁用。** 详见[接力支持边界](https://github.com/WXGopher/agent-companion/blob/v0.3.25/docs/RESUME.md)和[验收记录](https://github.com/WXGopher/agent-companion/blob/v0.3.25/docs/CODEX_DODEX_VALIDATION.md)。

macOS 包适用于 macOS 14+ Apple Silicon，使用 ad-hoc 完整性签名，未做 Apple 公证。

## English

Fix `acomp resume` startup failures with existing Codex / Dodex configurations:

- **Disabled MCP definitions.** Explicit `enabled=false` definitions no longer block resume because of leftover relative commands, working directories or unused OAuth settings. Native effective configuration must still confirm they remain disabled before launch. Active MCP and other compatibility checks remain in place.
- **Project configuration boundaries.** Follow the native Git-root rules instead of adopting another account's `.codex` above the repository as project settings. Empty `.git` directories do not hide a valid parent repository, and worktree file markers remain supported.
- **Older Dodex runtimes.** After validating the existing deployment binding, allow borrowing a native executable from the local official App or fixed standalone installation. The strict **0.159.3** requirement remains. Original history, settings and selected-account sources stay in use; installed Codex / Dodex entries are not upgraded or replaced. The native runtime may migrate history databases. Disposable fixtures verified reading, pagination, continued writes and writer locks across **0.155.0-alpha.16.4 → 0.159.3 → the older version**.

Automated validation: **275** core, **166** main-program and **15** `acomp` tests passed, totaling **456**; **2** existing real-data tests remain ignored. CLI integration passed **6/6**. All **15 native contracts passed in separate batches**: 13 with an outer sandbox, and 2 using their own test sandbox to avoid macOS's nested-sandbox restriction. Relevant macOS and Windows GNU Clippy checks, formatting and diff checks passed.

All four real macOS source/account combinations (Codex/Codex, Dodex/Dodex, Codex/Dodex and Dodex/Codex) passed native preflight, reached the TUI input prompt, and exited with status **0** via Ctrl-D. **No new model request was submitted, and subscription billing was not verified. Windows resume launch remains disabled.** See [resume support boundaries](https://github.com/WXGopher/agent-companion/blob/v0.3.25/docs/RESUME.md) and the [validation record](https://github.com/WXGopher/agent-companion/blob/v0.3.25/docs/CODEX_DODEX_VALIDATION.md).

The macOS package requires macOS 14+ on Apple Silicon and uses an ad-hoc integrity signature without Apple notarization.
