# Agent Companion v0.3.16

- Windows 启用 Dodex 支持时自动检查已有环境，缺少时部署，并注册或修复 `dodex` shell 命令；已有账号、会话和个人配置继续使用。
- 在 PowerShell、cmd 或 Git Bash 中运行 `dodex`，会在当前终端和工作目录启动第二实例的 Codex CLI。普通参数、`--help`、`--version`、`resume` 和 `exec` 均传给 Codex。
- 修复 shell 启动器的控制台行为，保留原生参数、标准输入输出、终端环境、Ctrl+C 处理和完整 Windows 退出码，同时隔离账号及会话环境。
- shell 命令优先安装到当前 PATH 中的受支持用户目录，并支持已有托管命令升级。无关同名命令会保留，冲突路径会显示在设置中。
- 更新中英文安装与升级说明，补充命令注册、旧版迁移、参数传递和控制台启动器回归测试。

升级旧版 shell 命令：退出旧版 Companion，替换文件后运行 `.\agent-companion.exe dodex --deploy`。仅以 `--check` 或 `--deploy` 开头时进入环境管理；桌面版仍可通过 **打开 Dodex** 菜单或 `.\agent-companion.exe dodex` 启动。

验证范围：自动测试覆盖命令注册、冲突保护、旧版迁移、PE 控制台转换、原生参数与工作目录、标准输入输出、账号环境隔离及完整 Windows 退出码。本版尚未完成 PowerShell、cmd、Git Bash 交互式 CLI 的完整手工回归；Dodex 真实桌面会话跳转仍待实机验收。macOS 需要 macOS 14+ 和 Apple Silicon，安装包使用 ad-hoc 完整性签名，未做 Apple 公证。

## English

- Enabling Dodex support on Windows now checks the existing environment, deploys one if needed, and registers or repairs the `dodex` shell command. Existing accounts, sessions and personal settings remain in use.
- In PowerShell, cmd or Git Bash, `dodex` starts the second-instance Codex CLI in the current terminal and working directory. Regular arguments, `--help`, `--version`, `resume` and `exec` pass through to Codex.
- Fix shell launcher console behavior, preserving native arguments, standard input/output, terminal settings, Ctrl+C handling and full Windows exit codes while isolating account and session environments.
- Prefer a supported user command directory already on PATH and upgrade previously managed commands. Unrelated commands are preserved, with conflicting paths reported in Settings.
- Update bilingual installation and upgrade guidance, with regression coverage for command registration, migration, argument forwarding and the console launcher.

To upgrade an older shell command, quit Companion, replace its files and run `.\agent-companion.exe dodex --deploy`. Only a leading `--check` or `--deploy` selects environment management. The desktop app remains available through **打开 Dodex** or `.\agent-companion.exe dodex`.

Validation scope: automated coverage includes registration, conflict protection, migration, PE console conversion, native arguments and working directory, standard input/output, account environment isolation and full Windows exit codes. Full manual regression of interactive CLI use in PowerShell, cmd and Git Bash has not been completed for this release. Real Dodex desktop thread navigation still awaits manual verification. macOS requires macOS 14+ and Apple Silicon; its bundle uses an ad-hoc integrity signature without Apple notarization.
