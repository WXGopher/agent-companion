# Agent Companion v0.3.7

## macOS 内置屏菜单栏对齐

- 修复 MacBook 切回内置屏后，数字落到菜单栏下方的问题。活动／完成数恢复到摄像头左侧，周剩余额度在右侧，与菜单栏图标同一行。
- 中间完整预留实体摄像头，两侧按实际数字使用窄宽度；收起高度与摄像头所在的菜单栏区域一致。外接主屏继续使用菜单栏中央的普通窄条，展开保持原宽度与顶边。
- 修复一位数剩余额度时 `left` 可能换行的问题，完整显示 `1% left`、`100% left` 和大计数 `99+`。
- 保留连续延展、屏幕顶边悬停、主屏跟随、长内容滚动、默认隐藏 Dock 和不透明设置标题栏。

## 安装与验证

- **macOS 14+ Apple Silicon：** 下载 `agent-companion-v0.3.7-macos-arm64.zip`。退出旧刘海和设置窗口，替换“应用程序”中的 **Agent Companion.app** 后重新打开。
- **Windows x86_64：** 下载 `agent-companion-v0.3.7-windows-x86_64.zip`；首次使用需要 [Microsoft Visual C++ v14 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)。
- 原生像素检查覆盖菜单栏两侧文字、摄像头避让和单行额度；17 种布局及显示器切换几何、连续动画、悬停、长内容、设置与公共逻辑回归继续执行。两平台在 CI 与发布流程执行构建、Clippy 和自动测试。
- 已在本机内置屏检查最终候选版的摄像头两侧数字、完整额度、同宽展开和 Esc 收起。
- 物理显示器拔插、全屏和真实鼠标悬停仍需单独手工验收；Windows 按编译与自动测试验证。详见 [验证范围](https://github.com/WXGopher/agent-companion/blob/main/docs/MACOS_NOTCH.md)。
- 两个 ZIP 附 SHA-256 校验和与 GitHub Actions 构建来源证明。macOS app 使用 ad-hoc 完整性签名，未做 Developer ID 签名和 Apple 公证；首次打开方式见 [README](https://github.com/WXGopher/agent-companion#macos-安装)。

## English

This patch restores the MacBook indicators to the menu-bar row beside the camera: active/finished counts on the left and weekly quota remaining on the right. The previous narrow layout placed them below the camera when returning to the built-in display.

The middle reserves the physical camera cutout. Narrow symmetric side areas fit the current numbers, and the collapsed height matches the camera/menu-bar band. External primary displays retain their centered menu-bar strip. Expansion preserves the width and top edge. The `left` suffix stays on one line even with a single-digit allowance.

Native pixel checks cover text on both sides, the empty camera reservation and single-line quota. Seventeen layouts and existing display-geometry, animation, hover, scrolling, settings and backend checks run alongside Windows x86_64 and macOS arm64 builds, Clippy and tests. Physical hot-plugging, fullscreen and live mouse hover remain separate manual checks; Windows validation covers builds and automated tests.

The final local candidate was also checked on a real built-in display for side indicators, complete quota labels, same-width expansion and Escape collapse.

Requires macOS 14+ on Apple Silicon or Windows x86_64 with the Visual C++ v14 x64 runtime. Quit the old app and Settings before replacing it. Archives include checksums and build provenance; the macOS app is ad-hoc signed without Developer ID signing or notarization.
