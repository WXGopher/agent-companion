# Agent Companion v0.3.11

## Windows 设置与订阅用量

- 设置分为 **Codex CLI**、**Taskbar & app** 和 **Integrations**。状态栏复用 macOS 的实时预览与组件布局，切换分区保留未保存草稿，修复鼠标、键盘、Apply 和恢复默认后的控件状态同步。
- 详情面板新增固定的 **Tasks / Usage** 导航。Tasks 提供 **Active / Finished** 分类；两页独立保留滚动位置，窗口尺寸保持稳定并限制在屏幕工作区内。
- Usage 显示 Codex 订阅额度、重置时间、累计和单日峰值 Token、最近七个有记录日期的用量、连续使用天数与最长任务时间。复用 Codex CLI 的 ChatGPT 登录，无需 API Key。
- 用量仅在内存中缓存五分钟，支持自动和手动刷新；离开页面取消未完成请求并清理后台进程。旧 CLI、未登录、网络错误和缺失指标有明确提示；部分接口失败时保留其他成功结果。
- 查询不启动模型任务。服务端统计可能延迟，Token 总数不等于剩余额度，也不提供账号级输入／输出／缓存拆分。

## 验证与安装

Windows 本地通过格式、Clippy、workspace 测试、release 构建和真实订阅读取验证。界面测试覆盖浅色／深色、100%／150%／200% 缩放、小窗口、键盘与鼠标操作、草稿保存、分类切换及滚动位置。macOS 共享设置组件由发布流水线的原生测试验证；本次未进行 macOS 实机人工验收。

GitHub Actions 构建 Windows MSVC x86_64 与 macOS arm64 安装包。校验下载包、SHA-256 及构建来源证明后公开；最终源码提交和构建流水线记录在 GitHub Release 中。

- Windows：退出旧程序后替换安装目录中的三个可执行文件，或从新包运行安装命令。保留已有配置。
- macOS：需要 macOS 14+ 和 Apple Silicon。退出后替换 app。安装包使用 ad-hoc 完整性签名，没有 Developer ID 签名或 Apple 公证。

## English

Windows now shares the macOS status-bar settings layout, with separate Codex CLI, Taskbar & app and Integrations sections. Drafts survive page changes and controls stay in sync after applying or restoring defaults.

The detail panel adds Tasks / Usage navigation, Active / Finished task filters and independent scroll positions. Usage reads Codex subscription limits, reset times, lifetime/peak tokens, recent reported days, streaks and longest turn through the existing ChatGPT login. Reads use a five-minute in-memory cache, support manual refresh, cancel on leaving and preserve partial results. No model task is started; missing data is shown as `—`.

Windows builds, Clippy, automated tests, live account reading and DPI/theme interaction checks passed locally. Both platform packages are built in GitHub Actions and verified before publication. Native macOS desktop acceptance was not performed for this change.
