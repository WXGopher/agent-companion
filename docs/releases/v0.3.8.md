# Agent Companion v0.3.8

## 选择刘海显示器

- 在 **Settings → Notch display** 选择 **Follow primary display（跟随主显示器）**，或指定任意已连接的显示器。选择立即生效、自动保存，无需点击 TUI 的 Apply。
- 指定屏幕断开时临时回到主屏，设置保留离线选择；重新连接后自动返回。固定屏幕的选择不受系统主屏变更或窗口焦点影响。
- 固定内置副屏时仍将任务数和周剩余额度放在摄像头两侧，与菜单栏图标同一行；外接屏使用普通窄条。展开继续保持同宽。
- 设置列表自动刷新，区分同型号屏幕；保存失败显示错误并恢复已保存选择。README 更新使用说明及设置截图。

## 安装与验证

- **macOS 14+ Apple Silicon：** 下载 `agent-companion-v0.3.8-macos-arm64.zip`。退出旧刘海和设置窗口，替换“应用程序”中的 **Agent Companion.app** 后重新打开。
- **Windows x86_64：** 下载 `agent-companion-v0.3.8-windows-x86_64.zip`；首次使用需要 [Microsoft Visual C++ v14 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)。
- 本地检查使用真实外接主屏与内置副屏的硬件坐标、UUID 和摄像头区域，验证两屏选择及隐藏原生窗口定位。隔离偏好测试覆盖保存、跨进程通知、同名屏幕及模拟断开／重连；原生设置渲染覆盖浅／深色、最小窗口、离线状态和错误回退。
- 保留 17 种刘海布局、连续动画、菜单栏文字、悬停和公共逻辑回归。两平台 CI 与发布流程执行构建、Clippy 和自动测试；屏幕顶边悬停测试使用有超时的条件等待，避免繁忙运行器上的过早断言，产品交互时长不变。
- 本轮桌面接口无法读取窗口，因此新控件现场操作、物理拔插和全屏仍需单独手工验收；Windows 按编译与自动测试验证。详见 [验证范围](https://github.com/WXGopher/agent-companion/blob/main/docs/MACOS_NOTCH.md)。
- 两个 ZIP 附 SHA-256 校验和与 GitHub Actions 构建来源证明。macOS app 使用 ad-hoc 完整性签名，未做 Developer ID 签名及 Apple 公证；首次打开方式见 [README](https://github.com/WXGopher/agent-companion#macos-安装)。

## English

Choose **Settings → Notch display → Follow primary display**, or pin the notch to any connected display. The choice applies immediately and saves automatically, independently of the TUI Apply button. If a pinned display disconnects, the notch falls back to the primary display while retaining the preference, then returns when it reconnects. Changing the primary display or keyboard focus does not replace a pinned choice.

A pinned built-in secondary display keeps task counts and weekly quota remaining beside the camera in the menu-bar row. External displays retain the narrow strip. Expansion preserves the width. The settings list refreshes automatically, distinguishes identical display names and restores the saved selection after a failed save. The README and settings screenshot are updated.

Local checks use real external-primary and built-in-secondary hardware coordinates, display identities and camera metadata with isolated preferences and hidden native windows. Tests cover persistence, cross-process notifications, duplicate names and simulated disconnection/reconnection. Native settings renders cover light/dark appearance, minimum size, offline choices and error recovery. Existing layout, animation, hover and backend checks remain in the Windows x86_64 and macOS arm64 CI and release workflows.

The desktop interface could not read windows this round. Live interaction with the new control, physical hot-plugging and fullscreen still require manual acceptance; Windows validation covers compilation and automated tests.

Requires macOS 14+ on Apple Silicon or Windows x86_64 with the Visual C++ v14 x64 runtime. Quit the old app and Settings before replacing it. Archives include checksums and build provenance; the macOS app is ad-hoc signed without Developer ID signing or notarization.
