# Agent Companion v0.3.3

## macOS 刘海连续延展

- 悬停后，刘海从原来的窄条平滑向下延展；顶部任务数和剩余额度始终留在原位，宽度保持不变。
- 移开后沿原路径回缩，收起途中再次进入会从当前位置继续展开。窗口尺寸、黑色轮廓与内容裁剪同步变化，取消原先淡入／上移与窗口突然变大的组合。
- 动画尺寸对齐屏幕像素，避免顶部文字因半像素位置而抖动。系统开启“减少动态效果”时直接切换，主显示器变化时立即重新定位。
- 新增实际 AppKit 面板的逐帧检查，覆盖普通屏和摄像头刘海、固定顶边和宽度、顶部数字像素、连续收起／反向展开、最终点击区域及减少动态效果。既有悬停、设置标题栏和配置保护检查继续运行。

## 安装与验证

- **macOS 14+ Apple Silicon：** 下载 `agent-companion-v0.3.3-macos-arm64.zip`。退出旧刘海和设置窗口，替换“应用程序”中的 **Agent Companion.app** 后重新打开。
- **Windows x86_64：** 下载 `agent-companion-v0.3.3-windows-x86_64.zip`；首次使用需要 [Microsoft Visual C++ v14 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)。Windows 功能与 TUI 保存行为保留。
- 两个平台由 CI 和发布流程执行构建、Clippy 和自动测试。实机检查边界见 [macOS 验证记录](https://github.com/WXGopher/agent-companion/blob/main/docs/MACOS_NOTCH.md)；逐帧离屏测试不等同于实机鼠标悬停确认。
- 两个 ZIP 附 SHA-256 校验和与 GitHub Actions 构建来源证明。macOS app 使用 ad-hoc 完整性签名，未做 Developer ID 签名及 Apple 公证，首次打开方式见 [README](https://github.com/WXGopher/agent-companion#macos-安装)。

## English

The macOS notch now extends smoothly downward from the existing strip. Counters, quota, width and the top edge stay in place while the window, silhouette and clipped content move together. Closing reverses the same motion, and re-entering during collapse continues from the current position and velocity. Frames align to backing pixels; macOS Reduce Motion switches immediately.

Native frame and rendered-counter checks cover ordinary and camera-notch layouts, opening, closing, interruption, final hit areas, reduced motion and display changes. Windows and TUI save behavior are retained. Requires macOS 14+ on Apple Silicon or Windows x86_64 with the Visual C++ v14 x64 runtime. Quit the old app and Settings before replacing it. Archives include checksums and build provenance; the macOS app is ad-hoc signed without Developer ID signing or notarization.
