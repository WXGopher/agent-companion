# Agent Companion v0.3.13

- macOS 默认显示菜单栏和 Dock，关闭刘海；三个入口独立开关并保存，隐藏全部入口后重新打开应用仍可进入设置。
- 设置中可手动部署或接入隔离的 Dodex 环境，默认关闭双开支持。已有兼容环境通过校验后直接接入；部署完成后由用户自行打开并登录。
- Codex / Dodex 分别显示周额度卡片，任务标注来源，用量、状态栏配置和会话跳转按实例管理。
- 修复子代理日志重复计入主会话导致任务数量与列表不一致的问题；修复其他额度项目覆盖 Codex 周额度的问题。
- macOS Usage 查询结果按实例缓存 5 分钟，从结果返回时开始计时。切换页面直接展示有效缓存，过期后重新读取，手动刷新可绕过缓存。

macOS 需要 macOS 14+ 和 Apple Silicon。应用包含 ad-hoc 完整性签名，未做 Apple 公证。双开不会复制现有凭证、历史或个人配置；停用支持会保留 Dodex 环境。Windows 沿用现有界面，并包含共享会话与用量解析修复。

验证说明：本地 Rust、macOS 原生界面和设置检查已完成；双开部署故障测试使用合成环境。未将 Windows 人工桌面检查、全新环境首次登录或无法访问的本机窗口自动化记为已完成。发布安装包由 GitHub Actions 构建，下载校验和来源验证后公开。

## English

- macOS now shows the menu bar and Dock by default, with the notch off. Each entry point has an independent saved switch; reopening the app restores access to Settings when all are hidden.
- Settings can explicitly deploy or connect an isolated Dodex environment. Second-instance support is off by default; compatible existing environments are validated and adopted. Users open Dodex and sign in themselves after deployment.
- Codex and Dodex have separate weekly-quota cards. Tasks identify their source, and usage, status-bar settings and conversation navigation stay tied to the correct instance.
- Fixed duplicate task counts caused by replayed parent metadata in subagent logs, and unrelated quota buckets overriding the Codex weekly allowance.
- macOS Usage caches completed results per instance for five minutes. Page switches immediately reuse fresh results, expired results are read again, and manual refresh bypasses the cache.

macOS requires macOS 14+ and Apple Silicon. The app has an ad-hoc integrity signature and is not Apple-notarized. Second-instance setup copies no existing credentials, history or personal configuration; disabling integration retains the Dodex environment. Windows retains its existing interface and receives the shared session and usage parser fixes.

Validation: local Rust, native macOS UI and Settings checks are complete; deployment fault tests use synthetic environments. Windows manual desktop checks, first sign-in to a fresh environment and unavailable local window automation are not claimed as completed. Release packages are built by GitHub Actions and published after download, checksum and provenance verification.
