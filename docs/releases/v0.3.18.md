# Agent Companion v0.3.18

- **macOS 仅保留菜单栏入口**：移除刘海、悬停展开、显示器选择与独立 Dock 入口。旧版隐藏入口偏好不会隐藏菜单栏，原有菜单栏位置继续保留；重新打开应用显示 Tasks 弹窗。
- **完整弹窗与亮暗主题**：顶部显示 Agent Companion、构建版本和实际运行数，等待输入另有提示。底部太阳／月亮按钮保存主题选择；切换主题或 Tasks / Usage 保留窗口尺寸、实例选择和滚动状态。
- **两平台统一任务状态颜色**：运行蓝色、等待／失败黄色、全部完成绿色、无任务或停止／暂停／未知灰色。混合任务先显示等待，再显示运行；失败不会计为成功完成。Codex／Dodex 独立显示状态，macOS 运行圆点呼吸动画遵守“减少动态效果”。
- **保留额度缓存语义**：状态变化与额度刷新独立。`69%*` 表示上次有效读数为剩余 69%，正在等待新的有效结果；取得有效更新后显示最新百分比并去掉星号。无读数显示 `—`，不把重置后的额度推算为 100%。
- **配置与全局指令手动双向同步**：Codex 双开页显示双方路径，分别提供 Codex → Dodex、Dodex → Codex 覆盖 `config.toml` 或 `CODEX_HOME/AGENTS.md`，备份已有目标并显示结果与备份路径。配置中的内嵌密钥会一并复制；**不复制 `auth.json`**，保留目标的登录存储、数据库和日志设置。没有自动同步；未保存的状态栏草稿会阻止配置覆盖，`AGENTS.override.md` 会提示但不会被替换。

升级前退出旧应用及设置窗口，再替换文件。Codex 配置、账号和双开环境继续保留。macOS 需要 macOS 14+ 和 Apple Silicon；安装包使用 ad-hoc 完整性签名，未做 Apple 公证。

本地验证：完整 macOS 原生菜单栏／弹窗测试、29 阶段真实设置窗口测试及核心同步回归通过。文件操作仅使用隔离测试配置。Windows 状态与界面通过无窗口测试及渲染检查，本版未做 Windows 人工桌面回归。已安装的 macOS Settings 窗口已检查，未覆盖真实配置；已安装弹窗的 CUA 获取超时，实机交互仍未验收，AppKit 日志确认其打开与重新打开。

## English

- **macOS now uses only the menu bar.** Remove the notch, hover expansion, display selection and separate Dock entry. Legacy hidden-entry settings cannot hide the menu bar; its saved position is retained. Reopening the app shows the Tasks popup.
- **Full popup header and light / dark themes.** Show Agent Companion, the build version and actual running count, with a separate input-needed indicator. The sun / moon button saves the chosen theme. Theme and Tasks / Usage switches preserve window size, instance selection and scroll positions.
- **Consistent task colors across platforms.** Running is blue, waiting/failure yellow, all completed green, and no tasks or stopped/paused/unknown states gray. Waiting takes priority over running; failures never establish successful completion. Codex / Dodex have separate status marks, and macOS running dots respect Reduce Motion.
- **Retain cached-quota behavior.** Task status and quota refresh independently. `69%*` means the cached last reading was 69% remaining, awaiting a valid update. A valid refresh shows the latest percentage without the star. Missing readings show `—`; a reset never implies 100% remaining.
- **Manual configuration and global-instruction sync in both directions.** The Codex 双开 tab shows both paths and separate Codex → Dodex / Dodex → Codex overwrites for `config.toml` or `CODEX_HOME/AGENTS.md`, with destination backups and visible results. Embedded config secrets are copied; **`auth.json` is never copied**, and destination account storage, database and log settings are preserved. There is no automatic sync. Unsaved status-bar drafts block config overwrites; existing `AGENTS.override.md` files are identified and left unchanged.

Quit the old app and Settings window before replacing the files. Codex configuration, accounts and the second-instance environment remain in place. macOS requires macOS 14+ and Apple Silicon; the bundle uses an ad-hoc integrity signature without Apple notarization.

Local validation: the full native macOS menu/popup suite, the 29-stage real Settings editor and core sync regressions passed. File operations used isolated fixtures. Windows status and UI checks passed headlessly with rendered previews; manual Windows desktop regression was not performed for this version. Installed macOS Settings was inspected without overwriting real profiles. CUA timed out acquiring the installed popup, leaving its live interaction unverified; AppKit logs confirm it opens and reopens.
