# Agent Companion v0.3.6

## macOS 刘海修复

- 修复长错误提示将展开面板撑出屏幕的问题。正文超过可用高度时滚动，底部为 Dock 留出空间，设置和退出入口始终可见。恢复命令按钮改用较短文字，避免窄面板截断。
- 修复滚动列表或打开右键菜单期间任务与额度暂停刷新。数据更新保留正文滚动位置，重复启动不会叠加刷新定时器。
- 修复点击紧凑刘海中间留白可能固定悬停状态却不展开的问题，整条刘海均可点击。
- 保留按主屏和摄像头间隔自适应的窄宽度、同宽连续展开、屏幕顶边悬停、周剩余额度、默认隐藏 Dock 和不透明设置标题栏。

## 安装与验证

- **macOS 14+ Apple Silicon：** 下载 `agent-companion-v0.3.6-macos-arm64.zip`。退出旧刘海和设置窗口，替换“应用程序”中的 **Agent Companion.app** 后重新打开。
- **Windows x86_64：** 下载 `agent-companion-v0.3.6-windows-x86_64.zip`；首次使用需要 [Microsoft Visual C++ v14 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)。
- 本版新增长内容滚动、底部操作固定、刷新保留滚动位置、菜单／滚动模式定时器回归。现有显示器尺寸、悬停、连续动画、设置及公共逻辑检查继续运行，两平台执行构建、Clippy 和自动测试。
- 原生离屏检查不等同于实机拔插或鼠标操作。本轮桌面自动化未能读取应用窗口，未新增物理拔插、全屏与真实鼠标悬停的手工验收；Windows 按编译和自动测试验证。详见 [验证范围](https://github.com/WXGopher/agent-companion/blob/main/docs/MACOS_NOTCH.md)。
- 两个 ZIP 附 SHA-256 校验和与 GitHub Actions 构建来源证明。macOS app 使用 ad-hoc 完整性签名，未做 Developer ID 签名和 Apple 公证；首次打开方式见 [README](https://github.com/WXGopher/agent-companion#macos-安装)。

## English

This patch fixes three macOS notch regressions: long errors extending the panel beyond the screen, paused snapshot refreshes during scrolling or context menus, and clicks in the blank middle of the compact strip failing to open the list.

Expanded content is bounded by the available screen height and bottom Dock. Long content scrolls while the summary, Settings and Quit remain fixed; snapshot updates preserve the body scroll position. The recovery command button uses a shorter label to fit narrow panels. Existing display-adaptive widths, continuous expansion, screen-edge hover, weekly quota remaining, hidden Dock default and opaque settings titlebar are retained.

Native regression checks cover both ordinary and camera displays, scrolling, footer pixels, error recovery and timer lifecycle. Windows x86_64 and macOS arm64 builds, Clippy and automated tests run in CI and the release workflow. Physical display disconnection, live mouse hover and fullscreen remain separate manual checks; desktop automation could not read application windows during this round.

Requires macOS 14+ on Apple Silicon or Windows x86_64 with the Visual C++ v14 x64 runtime. Quit the old app and Settings before replacing it. Archives include checksums and build provenance; the macOS app is ad-hoc signed without Developer ID signing or notarization.
