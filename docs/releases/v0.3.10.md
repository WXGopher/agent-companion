# Agent Companion v0.3.10

**开发中，尚未发布。** 本页记录待发布改动，不代表已有 v0.3.10 安装包；当前公开版本为 v0.3.9。

## 订阅用量与精简设置

- 刘海内新增 **Usage** 页面，复用 Codex 的 ChatGPT 登录读取订阅额度、重置时间、累计／单日峰值 Token、最近七个有记录日期的用量与使用记录；不需要 API Key。点击周额度卡片或 Usage 打开，Tasks 返回，宽度保持不变。
- 读取按需执行并支持手动刷新，收起或退出会取消读取；未登录、旧 CLI、缺失数据与网络错误均有明确状态。数据指标和访问方式见[说明](../MACOS_NOTCH.md#订阅用量开发中未发布)。
- 设置分为 **Codex CLI** 和 **Notch & app**；状态栏预览横向放在组件上方，组件仅显示一行名称，悬停查看说明，切换分区保留草稿。
- **Tasks / Usage** 切换固定在顶部，滚动后也可直接返回之前的任务分类。展开正文与间距缩小约一成，去掉重复大标题并收小 Token 数字；设置页字体也相应收紧。
- 五分钟内的已完成查询跨页面复用，来回切换不重复联网。额度和 Token 查询调用账号读取接口，不启动模型推理；macOS 菜单栏默认额度改为每 2 分钟检查本地记录，启动时立即读取，其他刷新间隔保留。

## 修复任务列表切换闪烁

- 修复从 Finished 切回 Active 时，尤其一侧为空列表时的闪烁。两个标签共用稳定的列表高度和原生滚动视图，切换时面板、顶部摘要和底部按钮保持原位。
- 切换标签从列表顶部开始；同一标签的数据刷新继续保留滚动位置。长列表仍可滚动，刘海宽度、收起／展开动画和显示器选择保持原有行为。
- 新增普通屏与摄像头屏共八种切换场景，覆盖空列表、单任务和长列表，检查中间帧不空白、固定元素像素稳定、滚动视图复用及滚动位置。该检查在旧版实现上失败，修复后通过；保留既有 21 种原生布局和双平台自动检查。

## 验证

既有双平台 CI 保留构建、Clippy 和自动测试。新增订阅检查覆盖空值、额度窗口、协议分帧与乱序回复、错误、超时、取消与进程清理，以及普通屏／摄像头屏的固定宽度布局。短窗口滚动时顶部导航保持原位；重复往返保留任务分类并复用五分钟缓存。真实 app 已检查从滚动到底部的 Usage 一键返回 Finished。macOS 原生检查、设置渲染、格式与 Clippy，以及 Windows GNU 三个程序交叉编译通过。正式发布前须重新验证最终提交与发布包；本轮未运行新的远端 CI 或发布工作流。物理显示器拔插与全屏检查仍在[未覆盖范围](../MACOS_NOTCH.md)中。

## English

**Unreleased development notes.** The latest public version remains v0.3.9. The new Usage page reuses your Codex ChatGPT login for subscription limits and account token activity without an API key. It supports manual refresh, cancels reads when dismissed, and keeps the notch width. Settings now separate Codex CLI from Notch & app, put the wide preview above the choices, and use one-line component names with hover descriptions.

Fix the flash when switching from Finished back to Active, especially when one list is empty. Both tabs now share a stable viewport and native scroll view, keeping the panel, summary and footer in place. Tab switches start at the top; same-tab data refreshes preserve the scroll position. Long lists still scroll, and the existing narrow width, expand/collapse animation and display preference are preserved.

Eight native switching scenarios cover ordinary and camera displays with empty, single-task and long lists. Intermediate-frame checks cover nonblank content, stable summary/footer pixels, scroll-view reuse and scroll position. The regression fails on the previous implementation and passes with this fix. The existing 21 layouts and Windows/macOS build, Clippy and test workflows remain in place.

No release workflow was triggered for this work. The final commit and packages still require release validation when publication is explicitly requested.
