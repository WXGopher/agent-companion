# Agent Companion v0.3.10（开发中，未发布）

发布已暂停；当前公开安装包仍为 v0.3.9。以下为待发布变更记录。

## macOS 订阅用量与导航

- 新增 **Usage** 页面，复用 Codex 的 ChatGPT 订阅登录，显示额度窗口与重置时间、累计／单日峰值 Token、最近七个有记录日期的用量、连续使用天数和最长任务时间；无需 API Key。
- **Tasks / Usage** 固定在面板顶部，滚动后也能一键回到原来的 Active / Finished 分类，展开宽度保持不变。
- 每次打开 Usage 先检查缓存：不足五分钟直接使用已有结果，达到五分钟才自动查询；首次无缓存时立即读取，手动刷新可立即查询。页面打开期间每五分钟刷新，离开后取消未完成的读取。数据仅留在内存中。
- 菜单栏默认额度改为启动时读取、之后每 **2 分钟**检查本地 Codex 日志；任务刷新间隔保持原样。统计读取不启动模型推理，不产生推理 Token 消耗。
- 未登录、旧 CLI、网络错误和缺失指标均有明确状态。缺失数据显示 `—`；账号 Token 统计可能延迟，不等同于剩余额度，也不提供账号级输入／缓存／输出拆分。详见[订阅用量说明](https://github.com/WXGopher/agent-companion/blob/main/docs/MACOS_NOTCH.md#订阅用量开发中未发布)。

## 界面与设置

- 修复 Tasks / Usage 切换闪烁：保留两个页面和各自滚动状态，共用稳定的内容区域，切页时不重新伸缩窗口。隐藏页面不再因滚动条被禁用而改变宽度；长错误提示与短屏滚动互不影响。
- 修复 Finished 切回 Active 时的闪烁，尤其是一侧为空列表的情况。两类任务共用稳定视口与原生滚动视图，切换时面板、摘要和底部按钮保持原位；切换后回到列表顶部，同一分类刷新保留滚动位置。
- 展开正文与间距缩小约一成，移除重复大标题，Token 主数字从 18 pt 调至约 13.5 pt；设置页字体和组件行高同步收紧。
- 设置分为 **Codex CLI** 和 **Notch & app**。横向状态栏预览放在组件列表上方；组件仅显示一行名称，悬停查看说明。切换分区保留未保存草稿，显示器与 Dock 偏好仍自动保存。
- 保留窄刘海、摄像头两侧菜单栏对齐、悬停展开、连续动画、显示器选择和 Windows 现有功能。

## English

Unreleased development changes. Publication is paused; v0.3.9 remains the latest public download.

The new macOS **Usage** page reads Codex subscription limits and account token activity using your existing ChatGPT login, without an API key or model inference. **Tasks / Usage** stays pinned above scrolling content and preserves your previous task filter. Completed reads are cached for five minutes across page switches and notch dismissal; opening an expired cache refreshes it automatically. Manual refresh remains available. Default menu-bar quota reads local logs at startup and every **two minutes**.

Fix Tasks / Usage flashing with persistent pages, a shared content area and independent scroll positions, including overflow on short screens. Hidden pages preserve their scrollbar geometry. Fix flashing between empty and populated Active / Finished lists with a stable viewport and native scroll view. Compact the expanded typography and spacing. Settings now separate **Codex CLI** from **Notch & app**, place the wide status-bar preview above one-line component choices, and preserve unapplied changes between sections.

Missing metrics remain `—`. Token activity may be delayed, does not measure remaining subscription allowance, and does not include account-wide input/cached/output breakdowns. Native layout, settings, cache boundaries, read-only protocol and process cleanup checks are included. Development commit `34c9afe` passed Windows MSVC and macOS arm64 CI. No v0.3.10 tag, GitHub Release or release artifacts have been created.

macOS requires Apple Silicon and macOS 14+. The app is ad-hoc signed for integrity, without Developer ID signing or notarization. Quit the old app and Settings before replacing it. Existing configuration is preserved. Published platform archives will include checksums and build provenance.
