# Agent Companion v0.3.17

- 修复 macOS 菜单栏在实例闲置、账号缓存超过五分钟且本地缺少有效额度时，直接隐藏该实例用量的问题。
- 菜单栏可见期间按实例每五分钟刷新账号用量，关闭面板后仍继续；后台和用量页共享查询与缓存，避免重复请求。
- 缓存过期、读取失败或额度重置后，保留最后已知数字并显示 `*`，悬停提示正在等待更新；有效新读数到达后恢复正常显示，不推算重置后的剩余额度。
- Codex / Dodex 的读数继续按实例、配置目录和运行程序隔离；停用实例或替换来源后清理旧读数。

macOS 需要 macOS 14+ 和 Apple Silicon。安装包使用 ad-hoc 完整性签名，未做 Apple 公证。Windows 行为不变。

验证：本地格式检查、Clippy、构建、完整 macOS 原生界面与设置窗口测试、核心服务测试通过。回归覆盖 299／300 秒边界、关闭面板后的刷新、失败重试间隔、过期标记、来源隔离、迟到结果和隐藏／重开缓存。测试使用合成数据及可控时间；未进行真实账号连续闲置或 Windows 人工桌面回归。

## English

- Fix a macOS menu-bar quota row disappearing when an idle instance's five-minute account cache expired and no valid local quota was available.
- Refresh account usage every five minutes per instance while the menu bar is visible, including with the panel closed. Background refresh and the Usage page share requests and caches.
- Keep the last known number with `*` after cache expiry, a failed read or a quota reset. The tooltip identifies readings awaiting an update; a valid new reading restores the normal display. No new-period allowance is inferred.
- Keep Codex and Dodex readings isolated by instance, home and runtime, clearing old data when a source is replaced or an instance is disabled.

macOS requires macOS 14+ and Apple Silicon. The bundle uses an ad-hoc integrity signature without Apple notarization. Windows behavior is unchanged.

Validation: local formatting, Clippy, builds, the full native macOS UI and Settings tests, and core server tests passed. Regressions cover the 299/300-second boundary, closed-panel refresh, retry throttling, stale markers, source isolation, late results and hide/reopen caching. Tests use synthetic data and controlled time; live-account idle tests and manual Windows desktop tests were not performed.
