# Agent Companion v0.3.30

- **设置中手动检查更新**：设置窗口提供公共的 **检查更新** 按钮，即时查询 GitHub 最新正式发布版本。按钮下方持续显示检查进度和结果；发现新版时显示 **查看 GitHub Release**，点击后打开对应发布页面。已是最新版或检查失败也有明确提示，失败后可重试。
- **由用户决定是否前往下载**：检查操作不自动打开浏览器，不下载或安装更新。只有点击发布页面链接才会打开浏览器；后台更新提示继续使用已有行为。
- **修复 Windows 任务栏额度提示裁切**：额度详情改用独立的原生悬浮窗口，避免被任务栏入口的小尺寸绘制区域裁切。提示随显示缩放调整、自动换行，并根据屏幕工作区放置。
- **修复打开面板后的提示残留**：点击任务栏额度打开面板时立即隐藏悬浮提示；鼠标离开入口前保持隐藏，防止提示遮挡面板或再次弹出。

本地分阶段验证：手动更新功能 **617 项测试通过、10 项忽略**；提示修复的应用测试 **129 项通过、7 项忽略**，另核验原生提示组 **3 项**、Windows 指示器组 **9 项**及显式运行的隐藏 Slint 测试 **1 项**。这些测试组存在重叠，不相加计算。格式、Clippy 静态检查及 Windows release 构建通过。测试与渲染截图使用合成数据；**最终真实桌面交互尚未收到手工确认，macOS 原生 CI 与最终发行包核验结果单独记录**。详见 [Windows 验证记录](https://github.com/WXGopher/agent-companion/blob/v0.3.30/docs/WINDOWS_VALIDATION.md)。

macOS 包适用于 macOS 14+ Apple Silicon，使用 ad-hoc 完整性签名，未做 Apple 公证。

## English

- **Check for updates from Settings.** A shared **检查更新** (Check for updates) button immediately queries the latest stable GitHub release. Persistent feedback below the button shows progress and the result. If a newer version is available, select **查看 GitHub Release** to open its release page. Up-to-date and failed checks have explicit feedback, and failures can be retried.
- **Open the download page only on request.** Checking never opens a browser, downloads a package or installs an update. Only the explicit release-page action opens the browser. Existing background update hints retain their behavior.
- **Fix clipped Windows taskbar quota tooltips.** Quota details now use a separate native popup instead of being clipped by the small taskbar readout's drawing surface. The tooltip follows display scaling, wraps its text and is placed within the screen's work area.
- **Dismiss stale tooltips when opening the panel.** Clicking the taskbar quota readout immediately hides its tooltip and keeps it suppressed until the pointer leaves the entry, preventing it from covering the panel or reappearing after the click.

Staged local validation: the manual update feature passed **617 tests with 10 ignored**. App tests for the tooltip repair passed **129 with 7 ignored**; targeted checks also passed **3 native tooltip tests**, **9 Windows indicator tests** and **1 explicitly run hidden Slint test**. These groups overlap and are not added together. Formatting, Clippy and the Windows release build passed. Tests and rendered screenshots use synthetic data. **Final real-desktop interaction has not received manual confirmation; native macOS CI and final release-archive verification are recorded separately.** See the [Windows validation record](https://github.com/WXGopher/agent-companion/blob/v0.3.30/docs/WINDOWS_VALIDATION.md).

The macOS package requires macOS 14+ on Apple Silicon and uses an ad-hoc integrity signature without Apple notarization.
