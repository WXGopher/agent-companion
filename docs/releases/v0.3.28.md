# Agent Companion v0.3.28

- **一键安装并配置 Dodex**：macOS 设置中的一个操作即可准备 Dodex App、完整 TUI 安装包、`dodex` 命令和 Companion 接入。支持全新安装；各项状态与进度分别显示，部分失败保留已完成内容，可继续安装。命令行 `agent-companion dodex-app --install` 使用相同流程。
- **独立对齐 App / TUI 版本**：Dodex App 跟随本机 Codex App，Dodex TUI 跟随本机 Codex TUI；两者版本可以不同。离线对齐保留较新的 Dodex，只要求退出待替换的副实例，作为来源的 Codex 可以继续运行。
- **简化双开设置**：以“安装并配置 Dodex”和“对齐版本”为主操作，监控开关、路径、手动 config/AGENTS 同步及在线更新收在“高级设置”。安装完成后由用户登录第二个账号；App 与 TUI 共用独立副账号目录，安装不复制主账号凭据、个人配置或 AGENTS 指令。

## English

- **Install and configure Dodex in one action.** macOS Settings prepares the Dodex App, complete TUI package, `dodex` command and Companion monitoring together. Fresh installations are supported. Separate status and progress indicators expose partial failures; completed steps are preserved for retries. `agent-companion dodex-app --install` runs the same workflow.
- **Align App and TUI versions independently.** Each Dodex App/TUI follows its corresponding local Codex App/TUI, whose version numbers can differ. Offline alignment preserves a newer Dodex and only requires the secondary processes being replaced to stop; the source Codex can keep running.
- **Simpler dual-instance settings.** Installation and version alignment are the main actions. Monitoring, paths, manual config/AGENTS synchronization and online updates are under advanced settings. Sign in with the second account after installation. App and TUI share an independent secondary profile; installation does not copy primary credentials, personal settings or AGENTS instructions.

Automated validation: **184 backend tests** and the **44-phase isolated Settings window check** passed, covering fresh setup, partial-failure recovery, account-directory bindings, command readiness, maintenance locking, version alignment and settings callbacks.

An installed local macOS build completed fresh setup, repeated installation and offline alignment while the source Codex kept running. Dodex App matched **26.930.61225** (build **13520**), and TUI matched **0.160.1**. After the user signed in with a second account, App and TUI shared that secondary identity, distinct from the primary account. Quota and usage-history queries succeeded; no model turn was created. Desktop automation was unavailable, so **Companion's Usage screen was not visually rechecked after login. Windows GUI remains unverified.** See the [dual-instance guide and validation record](https://github.com/WXGopher/agent-companion/blob/v0.3.28/docs/macos-dual-instance.md#v0328-validation-record). Windows CI compilation and automated checks are recorded separately in the build workflow.

The macOS package requires macOS 14+ on Apple Silicon and uses an ad-hoc integrity signature without Apple notarization.
