# 已知问题与维护事项

功能规划见 [路线图](ROADMAP.md)。本页保留实现限制和维护项，便于区分新功能与缺陷修复。

| 编号 | 项目 | 当前限制 |
| --- | --- | --- |
| M01 | 右键菜单深色模式 | 原生菜单未跟随 Agent Companion 的深色外观 |
| M02 | 本地管道访问权限 | 尚未显式绑定仅当前用户可访问的 DACL |
| M03 | 文档截图 | macOS 菜单栏、弹窗及设置截图随当前实现更新；部分 Windows 截图仍来自早期版本 |
| M04 | 日志时间 | 调试日志仍使用 UTC |
| M05 | 终端隐藏标签页定位 | 通过 `agent-companion-codex.exe` 启动的 Windows Terminal 会话已有精确身份定位；普通 CLI 可通过会话日志的存活写入进程寻找原终端，标签页和分屏仍依赖标题或可见文本匹配 |
| M06 | 运行中分屏定位 | Agent Companion 启动的会话不依赖助手消息；关闭分屏、拖到其他窗口或重建控件导致身份失效时回退原终端窗口。CLI 终端无法定位时不跳转到 Codex 桌面。IDE 不在本轮支持范围 |
| M07 | Codex hooks 信任状态 | 安装状态表示配置已写入；是否获准执行需在 Codex 的 `/hooks` 中确认 |
| M08 | 多种 Codex hooks 配置并存 | Agent Companion 保留已有内联 hooks 并将自己的条目写入 `hooks.json`；Codex 合并执行，可能提示同层存在两种表示 |
| M09 | Codex 原生提问接入 | 仅适用于 `agent-companion-codex.exe` 启动/恢复的 CLI 会话；app-server 与 WebSocket 为上游实验性接口。桌面端及普通 CLI 会话仍在 Codex 中作答；原生协议暂无多选 |
| M10 | Claude Code 验证 | 本机无法实际验证，整体标为实验性，新配置默认关闭 Claude 显示 |
| M11 | Codex 桌面存储兼容 | 分页历史读取为实验性，已验证本机 桌面应用 26.903.8094.0（后端 0.153.4）及 CLI 0.154.0 的存储结构；每轮最多检查最近 256 个主会话。不兼容时回退日志，暂时读取失败保留最多 30 秒；没有写入锁的旧客户端沿用十五分钟活动期限 |
| M12 | Codex 桌面原生回复 | 尚无已验证的公开附接通道；可观测的阻塞提问显示等待并跳回 Codex 作答，异步提问不误判为阻塞。Agent Companion 不向桌面数据库写入答案 |
| M13 | macOS CLI 精确跳转 | Terminal/iTerm2 按存活 Codex 进程的 tty 选择标签页，兼容 iTerm2 的独立会话服务，需要 Automation 授权；tmux、SSH、WSL、IDE 和其他终端不保证精确分屏。找不到原终端时提供复制恢复命令 |
| M14 | macOS 原生 GUI 验收 | 当前仅保留菜单栏入口。自动检查覆盖弹窗布局、任务／用量切换、滚动、主题、标题、状态圆点、额度缓存和设置同步；实机验证与自动检查范围见 [菜单栏说明](MACOS_MENU_BAR.md)。Terminal.app / iTerm2 的实际跳转仍受终端类型与 Automation 授权限制 |
| M15 | TUI 双开验收 | v0.3.31 移除桌面镜像；Codex／Dodex 独立程序包、账号、daemon 与更新。原生终端、安装更新和两个合成账号后台隔离纳入 macOS／Windows CI；真实账号计费与 Windows 人工桌面操作须单独记录，自动化通过不代表已完成全部实机计费验收 |
| M16 | 超大日志的首次状态读取 | 每个日志每轮读取最多 4 MiB。首次扫描时，若最近状态事件被更大的单条工具输出隔开，且没有兼容数据库，状态可能暂时不可用；新的有效事件到达后可恢复。不会为查找状态无限回扫日志，也不会仅凭进程存在显示运行 |
| M17 | 重复日志的精确同刻排序 | 同一会话存在多个物理日志、不同回合的最新事件时间完全相同时，纯日志去重仍可能优先保留已结束状态；数据库与日志合并的回合排序修复不覆盖这个历史边界 |
| M18 | 运行期间的停止证据缓存 | 已确认的停止证据仅保存在 Companion 进程内。数据库分页缺席不能证明线程已删除，因此数据库线程的少量身份元数据保留到明确归档或监控来源改变；没有固定条目上限，退出程序后清空 |

旧路线图中的刷新参数已经过时：点击详情不会触发额度请求；Claude 额度缓存为 60 秒，缺少凭据时等待 600 秒再尝试。参数本身不作为功能里程碑。

Codex 额度按各会话最后一条有效额度事件的时间选择：Windows 每 30 秒后台刷新，macOS 菜单栏每 2 分钟刷新本地记录；未更新日志文件修改时间或会话暂时没有活动时，仍会按间隔重新读取。数据以 Codex 已写入本地日志的记录为准。两个平台的 Usage 页联网统计均按实例保留五分钟缓存与刷新间隔。
